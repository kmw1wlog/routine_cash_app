# Mobile MVP Implementation Report

## 구현 요약

`루틴캐시` 모바일 MVP를 Next.js App Router + TypeScript + Tailwind CSS로 구현했다.  
앱은 온보딩 이후 `홈 / 계산 / 루틴 / 자료실 / 인증` 5개 탭으로 동작하며, 목표 카드 우선 UX, 보수적 계산 로직, 7일 루틴, 무료 우선 자료실, 데모 뱃지 흐름을 모두 localStorage 기반 데모 상태로 연결했다.

## 주요 화면

- 홈: 목표 카드 우선 노출, 오늘의 30분 미션, 무료 우선 참고자료, 인증 미리보기
- 계산: 현재 준비 금액, 목표 기간, 부족 금액, 주간/월간 추가수익, 알바 기준 시간, 부업별 예상 기간
- 루틴: active goal, 실행 진척도, 오늘 미션, 7일 루틴, 무료 우선 참고자료, 선택형 쿠키 자료 1개
- 자료실: 쿠키 지갑, 데모 충전, 무료 자료 우선 정렬, 선택형 자료 unlock
- 인증: 뱃지 보드, 데모 인증 버튼, 커뮤니티/실패 후기 예시

## 데모 데이터

- 목표 카드: 10대 후반~20대 12개, 30대 이상 6개
- 부업 데이터: 10개
- 자료 데이터: 총 14개
- 무료 자료 10개
- 쿠키 자료 4개
- 뱃지 8개
- 커뮤니티 피드 6개

## 계산 로직

- 기본 시급 가정: `10,000원`
- 부족 금액 계산: `goalAmount - currentSaved`
- 주간 추가수익: `remaining / targetWeeks`
- 월간 추가수익: `remaining / targetMonths`
- 일반 알바 기준 시간: `remaining / 10,000`
- 부업별 예상 기간: 부업별 월 순수익 범위를 주간/월간 추정치로 환산
- 홈 추천 조합 예상 기간: 핵심 부업 + 보조 부업 + 주간 저축 루틴을 보수적으로 합산한 데모 추정

## 자료실/쿠키 구조

- 초기 쿠키: `12쿠키`
- 데모 충전 패키지
- `10쿠키 / 2,000원`
- `30쿠키 / 5,500원`
- `60쿠키 / 9,900원`
- 실제 결제 없음
- 쿠키 자료 unlock 시 localStorage에 유지
- 홈과 루틴에서는 쿠키 충전 CTA 없이 참고자료 보기만 노출

## 쿠키 과금 유도 완화 장치

- 무료 자료 비율
- 14개 중 10개를 무료로 구성해 무료 비중을 약 71%로 유지
- 홈 쿠키 CTA 제거 여부
- 홈에 쿠키 충전 버튼과 쿠키 잔액 강조 UI를 넣지 않음
- 루틴 내 쿠키 자료 노출 제한
- 미션별 쿠키 자료는 최대 1개만 노출
- 결제 압박 문구 제거 여부
- `마감 임박`, `한정 할인`, `지금 안 사면 손해`, `첫 수익을 원하면 결제하세요` 같은 문구 미사용

## 안전 문구

공통 `SafetyNotice` 컴포넌트를 계산, 루틴, 자료실 화면 하단에 배치했다.

> 이 앱의 예상 기간과 수익은 데모 추정입니다. 수익은 보장되지 않으며, 투입 시간·숙련도·고객 확보 여부에 따라 달라질 수 있습니다. 초기비용이 크거나 수익을 보장하는 부업은 추천하지 않습니다.

- 홈에 `쿠키 충전` CTA 없음 확인
- 시나리오 B: 통과
- 기본 준비 금액 `100,000원`
- 부족 금액 `400,000원`
- 주간 추가수익 `100,000원`
- 일반 알바 기준 `약 40시간`
- 수익 보장 문구 없음 확인
- 시나리오 C: 통과

- 오늘의 미션 표시 확인

- 시나리오 D: 통과
- 자료실에서 초기 `12쿠키` 확인

- 새로고침 후 unlock 유지 확인
- 결제 압박 팝업 없음 확인
- 시나리오 E: 통과
- `390x844` 기준 가로 넘침 없음
- 하단 탭바 정상 표시
- 자료실에 과도한 결제 유도 문구 없음

## 남은 작업

- 실제 PWA 설치 흐름과 오프라인 캐싱은 아직 미구현
- 실제 백엔드, 인증, 결제, 커뮤니티 업로드는 미구현
- 데이터 편집용 관리자 화면 없음
- 앱 아이콘과 고유 브랜딩 에셋은 기본 favicon 수준
- 실제 사용자 피드백 기반 튜닝 전 단계
